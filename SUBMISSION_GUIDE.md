# Submission Guide

## GitHub Commands

Create an empty GitHub repository named:

```text
insight-analytics-pro
```

Then run:

```bash
git init
git add .
git commit -m "Build full stack analytics app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/insight-analytics-pro.git
git push -u origin main
```

## Suggested Repository Description

```text
Full-stack analytics dashboard with React, Express, KPI charts, campaigns, funnels, live events, and deploy-ready configuration.
```

## Why This Project Looks Strong

- It is truly full stack: frontend dashboard plus backend REST API.
- It runs without external database setup.
- It includes deployment scripts and production static serving.
- It has polished analytics UI, charts, filters, export endpoint, and live events.
